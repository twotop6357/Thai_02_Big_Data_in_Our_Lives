# 언어별 외부 블록 이미지와 생성 로딩

블록 이미지 설정은 `Assets/StreamingAssets/BlockArtwork/blocks_en.json`, `blocks_th.json`이다. 각 JSON의20개 항목이 `kind`, `id`, `image`를 연결한다. 이미지는 같은 폴더의 `Images/en`, `Images/th`에 배치하며 `_Eng`, `_Thai` 접미사로 구분한다. 자세한 교체 절차는 [배포 폴더 안내](../Assets/StreamingAssets/BlockArtwork/README.md)를 따른다.

프로그램 시작과 홈 복귀에서 두 언어를 비동기로 다시 읽는다. 완료 전 RFID 인식/시뮬레이터 입력과 Game 블록 초기화를 기다리고, 완료 후 두 선택 화면/F9의 목록·리더·드래그가 같은 런타임 Sprite를 사용한다. JSON과 이미지 경로만 바꾸면 다음 체험에 적용된다. PNG/JPG의 전체 영역/원래 비율/투명도를 사용한다. 태국어 연령4종은 현재 JSON에서 영어 이미지 경로를 명시하며 태국어 파일을 추가하면 경로만 교체할 수 있다.

`RfidBlockArtwork.asset`과 기존 `Assets/UI/Blocks` 이미지는 누락/오류 복구용 기본값이다. 런타임은 자산을 복제해 외부 Sprite를 연결하므로 원본 에셋/GUID를 덮어쓰지 않는다. 잘못된 언어 문서는 해당 언어, 잘못된 이미지 한 개는 해당 블록만 기본값을 사용한다. 로그에는 영문 문맥과 원래 예외를 보존한다. 같은 파일은 한 번만 디코딩하고 재로드 후 이전 런타임 Sprite/Texture를 해제한다. 이미지 교체는 인식 ID나 생성 팔레트를 바꾸지 않는다.

현재 진행: 그룹 블록 먼저 인식 → 버튼 또는 새 비그룹 입력으로 배치 화면 → 그룹1/물건1/색2를 완성 → **버튼으로 생성 시작** → 우측 박스의 배경 없는 회전 링 → 완료 이미지 → 새 버튼으로 결과/영상 진행. 블록 완성만으로 자동 생성하지 않는다. 생성 중에는 그 시점의 네 블록을 고정하고 RFID 인식 해제·교체·이동·전체 비우기를 무시한다. 종료 시 밀린 신호를 재생하지 않으며 종료 후의 새 RFID 입력은 정상 처리한다. 바뀐 조합이 완성돼도 새 버튼을 기다린다.

로딩은 붉은 분홍색의 링과 선두 포인트만 표시하며 두 부분의 RGB를 동일하게 사용한다. 흰 원판/고정 트랙/그림자는 없고 꼬리의 알파가0에서1로 부드럽게 이어진다. 실제 UI 메시로 만들며 시간을 멈춰도 일정하게 회전한다. 성공/실패/명시적 취소/제한시간/홈/화면 해제에서 숨기거나 파괴하고, 이전 요청의 종료가 새 요청의 로딩이나 RFID 잠금을 해제하지 않도록 기존 요청 소유권을 따른다. 생성 중 두 선택 화면의 모든 버튼 입력 잠금·타이머 Pause/Resume는 유지한다. RFID 신호는 생성 중 취소 사유로 사용하지 않는다.
