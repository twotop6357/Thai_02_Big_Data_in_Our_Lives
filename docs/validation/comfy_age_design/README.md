## 실제 적용

- BlockCatalog 제품별 ageVariants의 주제와 색 부위를 선택하며 기존 일반 제품 설명을 교체한다. 연령별 설명을 일반 물건 설명 뒤에 덧붙이지 않는다. 비니 커프/중절모 리본처럼 색 부위도 형태에 맞춘다. 전체 4연령 중 누락/중복/미등록 ID/빈 색 부위는 검증에서 거부한다. 연령 설정 없는 기존 제품의 일반 설명은 호환 유지한다.
- BlockSelection 실제 C#과 Python builder/기본 API·UI/StreamingAssets API를 동기화했다. 카탈로그 재로드(다음 Game 진입)부터 반영. Turbo4/512·CFG1·단일 생성, 원 HEX/RGB 전달·알파/480중앙보정·입력 잠금·세션 취소는 유지했다. 씬/모델/패키지는 이 작업에서 변경하지 않았다.
- 이 매핑은 연령 차이를 눈으로 구분하는 대표 예시이며 실제 개인의 선호나 사용 가능성을 제한하는 규칙이 아니다.

## 검증과 출처

- 최종 설정의 10종×4연령×2시드 = 80 실제 출력. 각 요청 API 해시·PNG 해시·선택/완성 프롬프트가 현재 설정과 일치함을 확인. 대표40개는 approved/report.json, 다른40개는 second_seed_final/report.json. 동일 전체 API 해시 출력만 재사용하며 원본 생성의 요청 ID와 출처를 보존한다.
- Python unittest 8/8. 원본 BlockSelection.cs를 PowerShell Add-Type으로 컴파일하고 1,440조합의 C#/Python 최종 프롬프트·연령형태·색 부위·HEX/RGB가 완전히 일치함을 확인. 누락/중복/미등록/빈 부위·불완전 선택 등 6개 거부 경로 확인. Unity 색 변환만 #RRGGBB 데이터 shim 사용.
- 원본 GeneratedImageFraming.cs의 순수 배열 코드를 별도 프로세스로 실행. 80/80 실제 PNG의 480RGBA/비어 있지 않은 알파·중앙±1px·24px여백 확인. 각 40셀 조합과 2248×5330 PNG 무결성/상하반부 육안 검토. 프레이밍 shim 중복 타입 오류는 새 PowerShell 프로세스에서 실행해 해결했다.
- Unity MCP가 Transport closed로 연결되지 않아 새 Editor 컴파일·JsonUtility 역직렬화·Play/Windows Player는 검증하지 않았다. 과거61 EditMode/앱16 PASS를 이번 변경의 새 실행 증거로 재사용하지 않는다.
- 현PC RTX5070Ti Laptop의 최종 대표40 출력 요청→PNG 중앙1.8795초/최대2.715초, 다른40 중앙1.733초/최대2.4초. 해당 원본 생성의 API 시간이며 앱 전체 시간/3060 시간으로 해석하지 않는다. 3060 실측은 여전히 미수행.
- verification.json / verify_final.py / verify_selection.ps1 / csharp_prompts.json에 실제 검사 보존. preview.png는 approved/all_products_by_age.png의 동일 바이트 사본이다.

## 남은 품질 한계

시드1206501에서는 아동 배낭/선글라스·의류가 여러 개 나오거나 잘린 사례가 남는다. 시계 밴드·자전거 바퀴/소매 등 원본부터 잘린 부분은 중앙보정으로 복구하지 않는다. 일부 재질/아날로그 밴드/접이식 구조는 지정과 다르며 접이식 우산은 펼쳐질 수 있다. 두 색이 전달되지만 모든 표면 픽셀 RGB·정확한 부위 배치를 보장하지 않는다. 따라서 전 시드 품질 승인/문제 완전 해결이라고 보고하지 않는다. 최종 대표 시드40개는 모든 연령 형태를 비교하기 위한 샘플이며 런타임의 랜덤 시드를 고정하지 않았다.

## 중간 자료

루트 report.json/원본 PNG는 첫 시도이고 review2/review3/seed2/final/second_seed는 조정 중 기록이다. 현재 대표 기준은 approved와second_seed_final 및 루트 verification/preview다. prompt_probe/prompt_probe2는 실제 파이프라인에서 짧은 문장을 직접 인코딩한 불채택 실험이며 활성 경로가 아니다. 원시 RGBA는 삭제하지 않고 보존했다. 미커밋, 커밋/push 없음.
