# UI-WEB-007 — 태국어 폰트 변경에 따른 문구 길이·배치 갱신

## 원본

사용자가 띄운 Figma 웹에서 `02. Big Data in our lives_ UI (TH)`·`(En)` 두 섹션을 선택하고 기존 내보내기 설정으로 일괄 내보낸 `browser_export.zip`(86개)을 썼다. `download/NN.png`는 ZIP 순서대로 푼 파일이고 원래 이름은 `zip_entries.json`에 있다. Figma는 선택·내보내기만 했고 수정하지 않았다. Figma MCP는 쓰지 않았다.

## 감지 (`zip_entries.json`의 `status`)

직전 내보내기(`../ui_web6/download`, 84개)와 이름·보이는 픽셀(알파 곱셈 후)로 비교했다.

- 태국어 문구 6개가 새 이름·새 크기로 바뀜: 그룹 제목·부제, 선택 제목, 결과 제목·부제, 영상 종료 문구. 깨져 보이던 모음 조합(예: "อายุใด", "มาดูกันว่า")이 새 폰트로 바로잡혀 글 길이가 달라졌다.
- 전체 화면 프레임 4개(그룹·선택·결과·영상 종료)의 변경 영역은 위 문구 자리뿐이다. 버튼 안내·칸·보드·배경·로고는 그대로다.
- 타이틀 프레임, 태국어 블록 21개, 영어 요소 전부는 같다.
- 새로 보인 2개(`Rectangle 11-1`, 타이틀 블록 제거 문구)는 이미 프로그램에 있는 `VideoEndPopup.png`·`TitleBlockPopupText.png`와 바이트가 같다.
- 6개 대상 PNG의 현재 바이트는 직전 내보내기와 같아, 프로그램 쪽에 별도 수정이 없었음을 확인했다.

## 적용 (`Tools/UI/apply_web7_assets.py`, 결과 `applied.json`, 원본 `before/`)

새 요소를 같은 ZIP의 전체 프레임 안에서 불투명 픽셀 기준으로 찾아(평균 오차 3.9~7.4) 그 좌표·크기로 `Lang_Th.json`을 고쳤다. PNG는 웹 원본 바이트를 그대로 복사했고 meta/GUID는 유지했다. `ExhibitionUIAssets`의 태국어 기본 사본(`defaultThai`)도 같은 JSON으로 갱신했다. 씬·스크립트 변경 없음.
