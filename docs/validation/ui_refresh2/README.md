# UI-REFRESH-002 — 로컬 가이드 적용

2026-10-29, Unity2022.3.62f3 Editor/Windows. 기준main/37723c7와 기존 미커밋 보존, Codex 단독 구현·검증. 사용자 제공 `Assets/UI/2_new`의1920×1080 가이드8장(TH/EN 각 타이틀·그룹·물품색·광고)과 요소24개를 사용했다. 영상/종료 화면은 변경하지 않았다.

## 반영

- 새 PNG24개의 원본 바이트를 기존 언어UI 경로/파일명으로 교체했다. 기존meta24개가 바이트 단위로 동일하여 GUID와 Sprite 참조를 유지한다. 교체 전 PNG 바이트는 런타임에 남기지 않았다.
- 불투명 픽셀의 색·모양을 가이드에서 찾아24개 요소를 원본 래스터 크기로 맞췄다. 정수 픽셀 단위 배치이므로 Figma의 소수점 경계를 재현하는 것은 아니며, 원본 가이드의 래스터 경계와 대조했다. 매핑/크기/RMSE는 `asset_mapping.json`, 파일해시는 `replacement_audit.json`에 남겼다.
- 타이틀 안내는 양언어 모두 x307/y879/1315×173, 그룹 보드는 y281→274. 그룹의 네 칸은 부모 보드와 함께7px 위로 이동한다. 나머지 공통 보드/슬롯은 기존크기/위치를 유지한다. 태국어 제목·부제/영어 광고 부제 등의 변경은 Lang JSON을 따른다.
- Lang_En/Th와 라이브러리 기본사본을 동기화했다. 기존 UI를 재생성하지 않고 세 씬의 해당 RectTransform만 갱신했다. LocalUIRefreshAuthoring은 영상 하위 컴포넌트의 직렬화가 전후 동일한지 확인했다. 일반 UIBuilder의 그룹 보드 좌표도274로 맞췄다.
- 사용자 승인에 따라 가이드8장과 중복 수입 PNG24개·meta/폴더를 `2_new`와 함께 삭제했다. 삭제 직전 빌드씬/에셋 라이브러리/블록아트맵에서2_new 참조0개, 절대 경로가 프로젝트 Assets/UI/2_new와 동일함을 확인했다. `cleanup.json` 참조. 검사 중 기본 Unity 실행 도구가 삭제 패턴을 차단해, 사용자가 명시 승인한 정리 범위에 한해서 도구가 제공하는 의도적 삭제 실행 옵션을 사용했다.

## 실제 검증

- `runtime.json`: **52항목 PASS**, TH/EN 각각4개 화면 캡처. 같은 실제 버튼 API로 짧은 시작·2초 토글·5초 홈, 미인식/필수 조합 게이트·블록 제거 후 배치 유지·재인식·로컬 색칠, 프레임 색/원래 크기, 그룹→배치 암전 없음, 광고 입력잠금·반복 아우라, 양언어 영상 선택·암전·실제 디코더0번 프레임·종료 팝업/홈·영상 텍스처 해제를 확인했다. 영상 종료는 끝부분으로 seek하여 검사했으며 전체 길이 시청은 아니다.
- `pixel_comparison.json`: **24개 정적 이미지 슬롯 대조 PASS**. 제공 가이드와 실제 렌더의 불투명 영역 비교, RMSE0.036~10.141/255. 소수점 래스터 반올림/안티앨리어싱 차이는 포함하며 투명 여백·그림자·블록 인식 결과/색칠 물건은 비교 대상에서 제외했다. `th_*`/`en_*`8장도 직접 확인했다. 가이드의 예시 Student를 고정 배경에 넣지 않고 실제 리더 내용으로 유지했다.
- `editor_apply.json`: 기존 영상 하위 직렬화 변경 없음. `final_references.json`: 정리 후 세 씬 누락스크립트0·누락Sprite0. 영상 이미지/영상종료 JSON의 기존값을 유지했다.
- `preserved_hashes.json`: Assets/Scripts 전체, 효과프리팹, 영상/종료이미지, 블록생성설정, 패키지 및 시작부터 변경돼 있던 vendor 파일을 포함한 **291파일의 SHA256 동일**. 기능/연출 소스·파티클 시간/동작·원본영상·운영설정 미수정. 컴파일오류0; 종료 때 apiUrl 미설정 진단은 기존 운영설정에서 발생했다.

## 도구와 남은 범위

`Tools/UI/match_refresh_assets.py`와 `apply_refresh_assets.py`는 수입용 도구로 원본2_new가 있어야 실행할 수 있다. 사용자 요청에 따라 원본 폴더를 삭제했으므로 재사용하려면 새 수입본이 필요하다. 기록 JSON에는 당시 파일명·매핑·해시가 남는다. `verify_refresh_runtime.cs`는 현재 에디터 실행 검증 도구이며 `verify_refresh_pixels.py`는 원본 가이드가 필요하다.

Windows Player 빌드/설치PC·실물버튼/RFID·장시간/Profiler 및 영상 전체길이는 이번에 수행하지 않았다. 기존 RFID-BLOCKS-001의 네이티브 마우스/F9 및 장비 검증 대기를 완료로 바꾸지 않는다. 미커밋/push 없음, Play종료/0_Idle.
