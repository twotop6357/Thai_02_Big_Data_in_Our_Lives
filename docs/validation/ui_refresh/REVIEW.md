## 확인한 차이

- TH 타이틀의 버튼 안내는 최신 Figma에서 English/Thai 병기이며, Press Once→Start·Hold2seconds→Thai/English 규칙을 표시한다. 기존 `ButtonHelpBox_th.png`(851×173)는 Thai 문구와 다른 안내 조합이므로 동일 이미지가 아니다. 영어 안내 PNG(876×173)도 같은 기존 레이아웃이어서 단순 크기 조절/언어간 복사로 대체할 수 없다.
- TH 광고 버튼 안내의5초 홈 행은 최신 컨텍스트에서 가운데 정렬이다. 기존 `ButtonHelpBox_recommendedAd_th.png`(766×153)에서는 왼쪽에 정렬되어 있다. 최신 완성 PNG를 확보해야 한다.
- TH 광고 결과 보드의998×537/x461/y320 및 영상 종료 보드1394×674/x263/y203은 확보한 컨텍스트에서 기존 값과 동일하다. 이를 이유로 다른 텍스트 이미지의 렌더 크기까지 같다고 추정하지 않는다.
- 변경된 배경/제목/부제/안내 전체 범위와 정확한 이미지 렌더 경계는 아직 미확인이다. TH/EN 위치를 동일하게 유지하고 영어 타이틀 버튼 안내는 태국어 기준으로 맞추라는 기존 사용자 정정도 후속 적용 때 보존해야 한다.

## 차단 원인과 재개

Figma는 다음 오류를 반환했다: `You've reached the Figma MCP tool call limit on the Starter plan.` 나머지6개 get_design_context, read-only use_figma 및27:537 버튼 안내의 download_assets 모두 같은 오류다. 권한 오류가 아니라 서비스 조회 한도이며, 실패 호출을 반복하지 않는다.

한도가 복구되면 확보하지 못한6화면부터 조회하고, 바뀐 개별 UI 노드의 PNG와 렌더 경계를 받아 기존 경로/GUID를 유지하며 교체한다. 또는 최신 내보내기 PNG와 정확한 배치 정보가 프로젝트에 제공되어야 한다. 전체 UI 재빌드는 사용하지 않고 기존 연출/파티클 프리팹·타이밍/물리버튼/영상 로직을 보존한다.

현 단계는 자료/문서 작업뿐이므로 Unity Play/컴파일/빌드는 실행하지 않았다. 기존 앱 파일의 시작 SHA256은 `app_preserved_hashes.json`에 기록했다. 작업 시작부터 존재하던 vendor ConfettiFullscreen 변경은 별도 사용자/에디터 변경으로 보존했다.
