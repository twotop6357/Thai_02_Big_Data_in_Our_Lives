# ALPHA-OPAQUE-001 / 2026-11-02

Codex 단독 구현·검증, main/3852ee6+기존변경 보존. 사용자 요청은 흰색 및 다른 색의 물체 내부 투명화만 수정하는 것이다. 진행 중 Claude의 RFID-LISTEN/PRESENCE 변경과 별도로 작업했고 해당 파일/씬/설정/패키지/모델을 수정하지 않았다. 교차 검증은 하지 않았다.

## 원인과 최종 변경

흰 배경+흰 물체를 BiRefNet이 같은 배경으로 오인하는 사례를 재현했다(`probe1`). 가방 본체와 우산 면은 알파가 완전히0으로 떨어져 단순 알파 임계값만으로는 복원되지 않았다. 회색 배경만 적용해도 많이 개선되지만, 파란 렌즈·노란 이어패드·흰 시계밴드 등 일부 재질은 여전히 잘못 분리됐다(`matrix1`). 반전RGB의 이중추론도 충분하지 않았다(`matte_gray_flags`).

최종은 기본 노드만 사용한다.

- BlockCatalog의 styleSuffix 중 제거용 배경 문구1개만 중간회색(#808080)/opaque로 변경. 최종 배경은 투명하다. 스타일prefix/물건·연령형태/색HEX·모델·해상도·4단계는 유지한다.
- 원본RGB의 R×G×B>0.65(흰색/옅은 명암), |R-G|+|R-B|>0.12(유색), R×G×B<=0.015(검정/어두운 재질)을 기존 분리 마스크에 보완한다. 회색 배경은 재질 보호에서 제외된다. 원본의 RGB를 다시 그리거나 바꾸지 않는다.
- bicycle가 포함된 제품문구는 기본 StringContains/ComfySwitchNode로 기존 분리를 사용해 바퀴/프레임/바구니 틈을 보존한다. 현재4연령 자전거 문구 모두 bicycle를 포함한다. 사용자 정의 자전거 문구를 바꾸면 이 라우팅 조건도 함께 검토해야 한다.
- 합친 지지영역의 신뢰도0.5 내부만1px 침식해 완전 불투명화한다. 최종은 기존 마스크+이 내부이므로 내부 밖의 원래 알파/안티앨리어싱은 정확히 유지한다. 낮은 그림자 확률을 무조건 불투명화하지 않는다.
- BiRefNet 추론은 여전히1회, 추가모델/커스텀노드/2차 이미지 생성은 없다. Comfy0.42의 기존 Mask/문자열/분기 노드를 사용한다. 필수 모델/런타임을 추가 다운로드하지 않는다.
