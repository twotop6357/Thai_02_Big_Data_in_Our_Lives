# UI-WEB-004 — 웹의 2번 콘텐츠 UI 비교·적용

2026-11-05 Asia/Seoul · Codex 단독 구현·검증 · main/3852ee6 + 기존 미커밋 보존. 커밋/push/배포 빌드 없음.

## 원본과 다운로드

[열린 Figma 웹](https://www.figma.com/design/c7zk0NV5ZHPNlLf5EgDHAb/?node-id=0-1)의 `02. Big Data in our lives_ UI (TH)/(En)`을 브라우저에서 직접 확인했다. **Figma MCP는 사용하지 않았다.**

- `browser_export.zip`: 웹의 두 섹션을 일괄 선택하고 File → Export에서 받은 64개 PNG, 14,671,266바이트. 전체 화면은 비교용이며 프로그램 배경에 통째로 넣지 않았다. `zip_entries.json`에 원래 이름과 인덱스를 보존했다.
- `video_hints_browser_export.zip`: 영상 좌상단 안내는 기존 내보내기 프리셋이 없어 후속 확인에서 두 안내에 1x PNG 내보내기를 추가하고, 전체 목록에서 그 두 요소만 선택하여 받은 ZIP이다. `video_hint_0.png`=영어 488×94, `video_hint_1.png`=태국어 452×94. 둘 다 웹 위치는 (40,40).
- `comparison.json`, `applied.json`: 기존 언어 UI 26개와 새 PNG의 픽셀·치수·가이드 내 위치를 일괄 대조한 결과와 실제 적용 좌표. 변경 전 PNG는 `before/`에 보관했다.

## 적용 범위

기존 PNG **15개를 웹 원본 바이트 그대로 교체**하고 영상 홈 안내 **2개를 신규 추가**했다. 기존 15개 meta/GUID와 Sprite 라이브러리 연결은 보존했다.

| 변경 | 내용 |
|---|---|
| 양언어 버튼 안내 8개 | 붉은 버튼 → 파란 원형 버튼, 영어 red → circular, 태국어 안내 및 홈 문구 정리, 새 너비/가로 정렬 |
| 연령 선택 제목 2개 | 영어 Which Age Group Are You In? 및 태국어 연령 질문으로 교체 |
| 태국어 타이틀 | (Big Data) 표기와 새 문구, 새 크기/위치 |
| 선택 부제 2개 | 물품 하나·색 두 개 부분을 분홍색으로 강조 |
| 태국어 종료 안내 | 줄 간격 증가, 높이 171 → 191, 세로 위치 조정 |
| 영어 타이틀 | 내용은 같으며 원본 대비 가시 픽셀 4개 차이도 원본 그대로 반영 |
| 영상 좌상단 안내 2개 | 기존 5초 홈 복귀의 정적 안내를 실제 재생 중에 표시 |

나머지 비교 대상 PNG 11개는 동일했다. 웹의 태국어 블록 17개(빨강 중복 포함)도 현재 ThaiBlocks의 대응 16개와 픽셀이 정확히 같았다. 공통 배경은 비교 화면의 대응 배경 영역과 일치하며 교체하지 않았다.

웹의 연령 보드는 **1칸**이지만 프로그램은 **4개 리더의 위치 인식과 네 칸 이동 연출**을 사용한다. 사용자의 동작/연출 보존 조건에 따라 기존 보드, 칸 위치, 전환을 유지했다. 새 연령 제목/부제의 y도 기존 헤더 영역에 유지하여 보드와 겹치지 않게 했다. 그 밖의 정적 안내는 새 가이드 좌표를 사용했다.

`Lang_Th/En.json`과 `ExhibitionUIAssets`의 기본사본을 함께 갱신했다. 기존 `figmaNode` 값은 이전 수입의 이력이며, 이번 원본 출처는 위 웹 링크/ZIP/대응표다.

## 영상 좌상단 안내

`ResultVideoController`에는 안내 오브젝트 참조와 표시/숨김만 추가했다. 실제 0번 프레임을 화면에 올릴 때 표시하고 정상 종료·실패·취소·복귀에서 숨긴다. 새 입력 구독/버튼/Skip/타이머/재생 상태 전이는 추가하지 않았다. 기존 5초 홈 복귀를 안내하며 Image는 raycast를 받지 않는다.

`2_Result`에 안내 Image와 언어 바인딩을 추가했다. 기존 107개 직렬화 객체 중 변경은 영상 패널의 자식 목록, 컨트롤러의 새 안내 참조, 로컬라이저의 새 바인딩/그룹 세 곳뿐이며 기존 객체 삭제는 0개다. `scene_preservation.json` 참조. 명시적 재작성 도구 `ExhibitionUIBuilder`에도 같은 안내 생성 경로를 추가했으며 씬 전체 재작성은 실행하지 않았다.

## 실제 검증

- Unity 2022.3.62f3 / Windows Editor / Game 1920×1080. 컴파일 오류 없음. 최종 Sprite/언어 바인딩 30개 확인.
- `runtime.json`: **98항목 PASS**. Thai → English → Thai, 각 언어 타이틀/연령/선택/광고/실제 영상/종료 팝업, 좌표·Sprite, 네 칸, 영상 0번 프레임/언어 선택, 짧은 입력 유지, 5초 홈 복귀. 생성 검증은 이전 생성 PNG를 주입했으며 새 AI 생성은 요청하지 않았다.
- `video_lifecycle.json`: **10항목 PASS**. 실제 디코더 재생 중 실패 주입 → 안내 숨김/자원 해제 → 재시도 표시 → 재생 중 5초 홈, 반복 진입/준비 중 취소와 RenderTexture 해제.
- `pixel_validation.json`: 기존 정적 요소 26개 렌더 대조 PASS(불투명 픽셀 RMSE 최대 0.1003/255). `video_hint_pixels.json`: 두 영상 안내는 위치/크기와 불투명 픽셀이 원본과 정확히 일치(RMSE 0). 양언어 실제 화면을 직접 확인했다.
- 실패 검증에서 영문 오류 로그 2건을 의도적으로 발생시켰다(실패 안내 + 원본 예외). 그 밖의 오류는 없었다. 로그를 숨기거나 원본 스택을 제거하지 않았다.
- `preservation.json`: 작업 전 688개 파일 중 666개 SHA256 동일. 의도한 기존 변경 21개 외 차이 1개는 Play 진입 때 Reporter가 갱신한 자동생성 `StreamingAssets/build_info`다. 기존 PNG meta, 다른 런타임 소스, 효과 프리팹, 원본 영상, RFID/생성/운영 설정, 패키지, ProjectSettings 및 Idle/Game 씬은 동일하다.
- Play 종료, 0_Idle, scene dirty=false. 교차 에이전트 검토는 수행하지 않았다.

영상 종료는 끝부분으로 seek해서 검증했다. 두 영상 전체 길이 연속 시청, Windows Player 재빌드/배포, 실제 버튼·RFID 장비 및 장시간 실행은 이번에 수행하지 않았다. 기존 배포 실행 파일은 그대로이며 다음 빌드부터 UI가 포함된다.
