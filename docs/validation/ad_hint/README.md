# UI-ADHINT-001 — 광고 화면 입력 3초·버튼 안내 페이드

2026-11-05 Asia/Seoul · Claude 단독 구현·검증 · main/3852ee6 + 기존 미커밋 보존. 커밋/push/배포 빌드 없음. 교차 검증 없음.

## 동작

- 광고 효과 시작 3초 뒤 입력을 연다. 폭죽은 약 6초 자연 종료까지 계속 재생된다. 이전에는 폭죽이 끝나야 입력이 열렸다.
- 버튼 안내는 입력이 열리는 시점에 0.25초 페이드로 나타난다. 이전에는 입장과 함께 바로 보였다. 페이드는 입력을 잠그지 않는다.
- 폭죽 중 버튼을 누르면 암전 뒤 효과를 정리하고 영상으로 간다. 3초 시점에 버튼을 이미 누르고 있었다면 기존 규칙대로 한 번 뗀 뒤 다시 눌러야 한다.
- 안내는 누르면 사라지고, 영상 실패로 광고에 돌아와 입력이 가능해지면 다시 나타난다. F10 패널처럼 다른 기능이 입력을 잠가도 사라졌다가 돌아온다.

변경: `AdProductHighlight`의 입력 해제와 효과 진행 분리, `ResultVideoController`의 안내 제어, `2_Result`의 참조 1개, Builder. 3초는 `AdProductHighlight.InputLockSeconds` 상수다.

## 실제 검증

Unity 2022.3.62f3 / Windows Editor / 1920×1080. `runtime.json`: Play **34항목 PASS**, 양언어, 이전 PNG 사용(새 AI 요청 없음).

- 입력 해제 3.006/3.000초, 안내 페이드 0.266/0.250초, 폭죽 5.745/5.904초.
- 잠금 중 안내 알파 0, 해제 시 폭죽 재생 중, 페이드 중 입력 잠금 없음, 폭죽 중 입력으로 영상 첫 프레임 0 도달, 폭죽 자연 종료 후 안내 유지.
- 영상 리소스 누락 주입 실패 후 안내 복귀·재시도 성공, 효과 도중 비활성화 시 정리와 입력 복구, 5초 홈.
- 콘솔 오류는 의도한 실패 주입 건(언어당 로그 2건)뿐이다.
- 첫 실행은 검증 스크립트가 잠금 해제 직후 버튼을 떼지 않고 5초 누르기를 시작해 멈췄고, 앱이 아니라 스크립트를 고쳤다.
