## 원본 보존 확인

- 작업 후 `E02-S0` 검색 12개(태국어 6 + 영어 6), 복제본 없음. 복제 때문에 TH/En 섹션 폭이 4065로 자동 확장된 것을 발견해 원래 값 2194로 되돌렸다(위치 13586/11232, -284, 높이 18379 그대로).
- 첫 시도에서 클릭이 영어 섹션 전체를 잡아 섹션째 복제됐고(1723-2390), 즉시 그 복제본만 삭제했다. 한 번은 검색창이 닫힌 상태에서 Ctrl+A와 문자가 캔버스로 들어갔으나 실행 취소 기록상 선택 변경뿐이었다(내용 변경 없음).
- 두 섹션을 기존 설정으로 다시 내보낸 `after_browser_export.zip`(84개)을 11-06 내보내기와 비교: 84개 수와 로고·영문 요소 대부분 동일. 차이는 태국어 영상 종료 문구 오탈자 수정("น ำ"→"นำ"), 태국어 선택 버튼 안내 문구·위치, 레이어 이름 2개(E02-S02 끝 공백 등) 같은 문구·이름 수정으로, 이번 작업에서 하지 않은 디자이너 편집이다. 이번 작업 범위 밖이라 프로그램에 반영하지 않았다.

## 적용

- `Tools/UI/apply_logo_split.py`: 배경 6개를 받은 바이트 그대로 교체(meta/GUID 유지, `before/` 백업). 교체 전 로고 상자 밖이 기존 배경과 같은지 검사(최대 채널 차 16 이하): 타이틀 RMSE 0.079(최대 13), 나머지 5개 0.
- `Assets/Editor/LogoAuthoring.cs`: 4개 배경(타이틀, 그룹 패널, 선택 패널, 광고 패널) 바로 위 형제로 `NSMLogo` 이미지(1746,40,135×116, raycast 없음)를 추가. 배경과 같은 부모라 패널 전환·페이드를 그대로 따른다. 영상 화면은 이전에도 로고가 없었다. `ExhibitionUIBuilder`의 배경 생성도 같은 함수를 호출한다. 씬 변경은 추가만(0_Idle·1_Game·2_Result 삭제 줄 0).

## 실제 검증

Unity 2022.3.62f3 / Windows Editor / 1920×1080. `runtime.json` **12항목 PASS**: 양언어 타이틀·그룹·선택·광고에서 로고 이미지 1개 표시. `before_after.json`: 이전 실행 스크린샷 5장과 비교해 로고 상자 밖 RMSE ≤0.08, 24 초과 차이 픽셀 0. 로고 상자 안 RMSE 6.6은 프레임 렌더(벡터)와 PNG 로고의 가장자리 안티앨리어싱 차이. `runtime_contact.png` 직접 확인. 콘솔 오류 0, Play 중지/0_Idle.
