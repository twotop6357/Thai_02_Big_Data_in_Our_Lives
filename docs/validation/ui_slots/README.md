# UI-SLOTS-002 — 용도별 칸 배치와 그룹 칸 축소 이동

2026-11-05 Asia/Seoul · Claude 단독 구현·검증 · main/3852ee6 + 기존 미커밋 보존. 커밋/push/배포 빌드 없음. 교차 검증 없음.

## 원본

Figma MCP 없이 사용자가 띄운 웹에서 일괄 ZIP으로 받았다.

- `slots_browser_export.zip` (`download/`, `zip_entries.json`): 양언어 그룹 보드·그룹 칸(People)·제품 칸·색 칸 2개, 10개 PNG. 받은 뒤 추가했던 내보내기 설정은 지웠다.
- `backgrounds_browser_export.zip` (`backgrounds/`): 양언어 4화면 배경 8개. 배경은 프레임 자체 채우기라 프레임을 임시 복제해 UI 레이어만 제거하고 내보낸 뒤 복제본 8개를 삭제했다. 원본 프레임은 수정하지 않았다.

## 동작

- 리더 4대는 그대로 어떤 블록이든 인식하고, 화면 칸은 용도로 고정한다: 좌상 그룹, 우상 제품, 좌하·우하 색. `RfidReaderSelection.DisplayBlock(slot)`이 리더→칸 대응을 맡는다.
- 색 칸은 먼저 놓인 순서로 채운다. 블록이 있는 동안 칸을 유지하므로 한쪽 색을 빼도 다른 색이 움직이지 않고, 빈자리는 다음 색이 채운다. 생성에 쓰는 주색/보조색은 **화면 칸 순서**를 따른다(이전: 리더 번호 순서).
- 같은 종류가 칸보다 많으면 먼저 놓인 블록만 표시하고 조합은 미완성으로 둔다(안내/진행 차단). 표시된 블록을 빼면 대기 블록이 이어받는다.
- 웹의 선택 화면 Student 그림은 예시로 보고 넣지 않았다. 선택 화면에서 그룹 블록이 빠지면 그룹 화면의 People/ผู้คน 칸 리소스를 252×252로 재사용한다(사용자 지시).
- 그룹→선택 전환: 그룹 칸 하나만 0.5초 InOutSine으로 이동하며 424→252로 줄어 좌상 칸에 인계한다. 나머지 세 칸은 페이지와 함께 페이드한다.

## 적용 범위

그룹 보드 504×504(`BoardImage.png` 바이트 교체, GUID 유지), 칸 PNG 6개 신규, 그룹 배경과 선택 배경 교체(meta 유지), 선택 배경은 제목 뒤 Rectangle 35 위치가 언어마다 달라 언어별 PNG 2개 추가. 그룹 제목/부제를 웹 위치로 이동. 웹 좌표는 영어 그룹 칸이 태국어보다 1px 아래다(원본 그대로). 타이틀·광고 배경은 웹과 사실상 동일해(RMSE 0.07, 0) 교체하지 않았다.

## 실제 검증

Unity 2022.3.62f3 / Windows Editor / Game 1920×1080.

- EditMode **135/135 PASS** (용도별 칸 신규 테스트 포함). 컴파일 오류 0.
- `runtime.json`: Play **131항목 PASS**, 양언어. 칸 좌표, 빈 칸 리소스, 리더 순서를 섞은 배치, 색 칸 유지/재충전, 제품 중복 대기, 그룹 제거 후 페이지 유지·진행 차단·재인식, 자동 진행, 전환 중 취소·레이어 정리, 5초 홈. `motion`에 프레임별 크기/위치 기록(424→252 단조 감소, 0.484/0.493초). 이 실행은 언어별 선택 배경을 연결하기 **전**이다.
- `flow.json`: 최종 리소스로 Play **48항목 PASS**, 양언어. 타이틀→그룹→선택→결과(이전 생성 PNG 주입, 새 AI 요청 없음)→광고→영상 0번 프레임→끝 근처 seek→블록 제거 후 타이틀. 전체 바인딩 스프라이트 일치, 언어별 배경이 패널을 채움.
- `pixel_validation.json`: 웹 프레임과 RMSE. 칸 영역 1.62, 그룹 보드 영역 3.27, 안내 위쪽 전체 2.5~3.7. 남은 차이는 웹 보드의 배경 흐림 효과(PNG로 재현 불가, 기존 선택 보드와 동일)와 제목 가장자리다.
- 콘솔 오류 1건은 첫 검증 스크립트가 버튼을 뗀 뒤에 진행되는 입력을 잘못 눌러 생긴 것으로, 프로그램 결함이 아니며 스크립트를 고쳤다. 최종 실행의 오류는 0건이다.
- Play 중 `TCP 10123 AddressAlreadyInUse` 경고: 다른 Unity(PID 7412)가 포트를 쓰고 있었다. 실제 RFID 소켓은 이 실행에서 시험되지 않았다.
