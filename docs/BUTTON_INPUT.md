# 씬 연결과 전시 버튼

## 관람객 조작

2026-10-30 변경: ComfyUI 이미지 생성 중에는 **두 선택 패널 모두 모든 버튼 입력(짧은 누름·5초 유지 포함)을 버린다.** 계속 안내도 숨긴다. 성공/실패/취소/제한시간/화면 종료 시 잠금을 해제하고, 버튼을 놓은 뒤 새로 눌러야 한다. 실패/취소 후 완전한 조합의 배치 패널에서 짧게 누르면 재시도한다. 이 조건이 아래의 일반5초 홈 규칙보다 우선한다. 생성 중 무입력 타이머는 Pause하고 종료 시 Resume/Reset한다. 하드웨어 블록 변경·제거와 프로그램 복귀는 계속 취소를 전달한다.

1. `Assets/Scenes/0_Idle.unity`에서 시작한다. 초기 언어는 Thai(th)다.
2. 타이틀에서 숫자 `1` 또는 숫자패드 `1`을 짧게 눌렀다 놓으면 **현재 언어**로 체험을 시작한다. 2초 유지와 구분하기 위해 놓는 순간 판정한다. 빠른 두 번 누름으로 언어를 고르던 방식은 제거했다.
3. 타이틀에서 연속 **2초 유지**하면 Thai ↔ English를 한 번 전환한다. 안내 이미지만 0.25초 페이드아웃 → 언어별 이미지·좌표 교체 → 0.25초 페이드인한다. 배경은 유지한다. 누른 채 계속 있어도 언어는 반복 전환하지 않으며, 놓을 때 체험을 시작하지 않는다.
4. 타이틀 외에는 언어를 변경할 수 없다. 연령 선택은 연령 블록1개, 물품·색상 배치는 네 블록 모두 인식하고 생성 중이 아닐 때 버튼 안내가 페이드인한다. 필수 블록이 부족하면 짧은 입력을 무시하며, 블록을 제거하면 안내를 숨기고 진행을 다시 차단한다. 연령 인식 후 짧은 입력은 물품·색상 화면으로, 네 블록으로 이미지 생성이 완료된 뒤의 짧은 입력은 추천 결과 화면으로 이동한다. 블록이 부족해도5초 홈은 사용할 수 있다.
5. 추천 결과 화면의 짧은 입력은 현재 언어의 설명 영상을 재생한다. 영상 실패 후 짧은 입력은 재시도한다. 영상이 끝나면 블록 제거 안내 이미지를 표시한다. 네 블록 제거 신호가 모두 들어오면 홈으로 이동하며, 완료 안내에서 짧은 입력도 홈으로 이동하는 대체 경로다.
6. 어느 단계에서든 **연속5초 유지**하면 홈으로 돌아온다. 타이틀에서는 이미 홈이므로 추가 씬 로드는 없다. 타이틀에서5초까지 유지한 경우2초 시점의 언어 전환은 한 번 일어난다.
7. 홈 복귀 시 작업·선택·생성 이미지·영상 자원을 해제하고 무입력 타이머를 재개한다. **현재 언어 모드는 유지**한다. 앱을 다시 실행하면 초기 Thai로 시작한다.

전환 직후 버튼을 놓아야 다음 누름을 받는다. 포커스 상실·어댑터 비활성화는 진행 중 누름을 취소하며, 유지 시간은 비례 시간(Time.timeScale)에 영향을 받지 않는다. 연타·장시간 유지·정확히2/5초에 놓는 경계값을 순수 입력 테스트에서 확인한다.

그룹 인식 후 계속 입력을 받으면 암전 없이 네 칸이 물품·색상 배치 위치로 함께 이동한다. 이동 중이나 도착 후 블록 인식이 해제돼도 이전 패널로 돌아가지 않는다. 현재 배치 화면에서 해당 슬롯만 빈칸/미인식 상태가 되고, 필수 블록이 다시 완성될 때까지 계속 안내와 짧은 진행 입력은 차단한다.

## 키보드와 장비 연결

- Idle 루트의 `ButtonInputSimulator/KeyboardButtonSimulator`를 끄면 숫자1 어댑터가 비활성화된다. 기존 DontDestroyOnLoad·중복 제거·포커스 복구 동작을 유지한다. Game에서 직접 Play하면 전시 매니저와 어댑터가 없으므로 Idle에서 시작한다.
- `GameManager.SetButtonPressed(bool)`: 실제 물리버튼 어댑터의 메인 스레드 진입점. 눌림/놓임을 전달하며, 버튼 누름은 무입력 타이머도 갱신한다. 연결 해제 시 `ResetButtonInput()`을 호출한다. 자동반복 신호를 새 누름으로 보내지 않는다.
- 키보드와 실제 장비를 동시에 사용할 때는 키보드 어댑터가 장비 상태를 덮지 않도록 먼저 끄거나 입력 병합을 별도로 구현한다. 실제 RFID/버튼 드라이버는 이번 UI 작업 범위에 없다.
- Game의 기존 에디터 시뮬레이터는 숫자2/3/4/5로 Group/Product/Color1/Color2 목록을 열고 같은 키로 해당 인식을 해제한다. 개발용 목록은 텍스트지만 관람객 화면은 이미지다. `showEditorDiagnostics`를 켜면 기존 상태·재시도/취소 개발 패널을 표시한다. Player에는 이 개발 패널이 없다.
- `ResultVideoController.SetBlockPresent(int slot, bool present)`: 결과/영상 화면에서 센서가 블록 상태를 전달할 메인 스레드 진입점. 0=Group,1=Product,2=Color1,3=Color2. 에디터 완료 안내에서 숫자2/3/4/5는 각 블록을 제거한 것으로 처리한다.

## 설정과 연결 API

- 버튼 유지 기준은 요구사항대로 코드 상수2초/5초다. `Settings.json`의 과거 `buttonDoublePressIntervalSeconds`는 호환을 위해 파일에 남아 있지만 더 이상 사용하지 않는다. 공통 설정의 비동기 로드·90초 무입력 대체 정책은 유지한다.
- `GameManager.CurrentLanguage` / `LanguageCode`: 현재 모드. `HasLanguageSelection`은 활성 관람객 세션 여부이며 홈에서는 false지만 모드는 유지한다. `IsLanguageChanging` 동안 체험 시작을 막는다.
- Game 진입 성공 시 `[GameManager] Game started. Language: Thai (th).` 또는 English(en)를 한 번 기록한다. 프로그램 로그는 선택 언어와 관계없이 영문이다.
- `ShortButtonPressed`: 현재 화면의 짧은 입력 구독. 화면 비활성화 시 반드시 해제한다. `TryOpenResult()`는 Game의 유효 이미지가 있을 때만 이동한다.
- `ReturnToIdleManually()`: 수동 복귀만 MoveIdleEvent를 발행한다. 무입력 복귀는 공통 API의 move_idle_timeout 기록을 보존한다.
- `SessionCancellationToken`: 콘텐츠 작업에 화면 수명 토큰과 함께 사용한다. Game→Result에서는 같은 세션·언어·이미지를 유지하며 홈 복귀에서 취소한다.

이미지 매핑·좌표·영상 설정은 [IMAGE_UI](IMAGE_UI.md)를 참조한다. 실제 검증과 미검증 범위는 [HANDOFF](agents/HANDOFF.md)의 UI-LANG-001에 기록한다.
