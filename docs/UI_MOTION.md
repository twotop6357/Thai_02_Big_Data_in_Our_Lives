# UI 연출 규칙

2026-10-30 / COMFY-RESTORE-001: ComfyUI 생성 수명에도 공통 입력 잠금을 적용한다. 선택 패널 종류와 관계없이 생성 완료/실패/취소까지 짧은 입력과5초 유지를 모두 버리고 계속 안내를 숨긴다. 종료 시 버튼 상태를 초기화해 완료 직전 누름이 뒤늦게 실행되지 않는다. 기존 패널·물건·영상 연출은 유지한다.

UI-MOTION-001은 기존 체험 기능에 시각 연출과 그 연출 구간의 입력 잠금을 연결한다. 언어 선택/2초 토글·5초 홈 조건, 블록 선택·색칠·저널·결과 텍스처, 영상 선택/재생/재시도/블록 제거 조건은 유지한다. 추가 사용자 승인(UI-GATE-001)에 따라 계속 안내/짧은 입력은 해당 단계의 필수 블록 인식 완료에 연결한다. UI-SLOTS-001에서는 그룹→배치의 네 칸 이동을 적용하고, 이동 시작 후 블록이 미인식돼도 배치 화면을 유지한다. PNG/MP4/언어·콘텐츠 JSON과 최종 디자인 배치도 유지한다.

## 공통 시간과 움직임

| 역할 | 적용 |
|---|---|
| 안내 팝업 | 배경을0.25초 어둡게 만든 후 카드0.3초 등장 |
| 안내 팝업·블록 신규 배치 | 크기0 → 실제 디자인 크기, OutBack0.3초 |
| 블록 칸 화면 진입 | 네 칸 동시에0.25초 InOutSine 페이드, 크기 유지 |
| 그룹→물품·색상 배치 | 암전 없이 페이지 내용 동시 교차페이드0.5초. 그룹 칸 하나가 불투명하게0.5초 InOutSine으로 이동하며 424→252로 줄어 좌상 그룹 칸에 인계(UI-SLOTS-002). 나머지 세 칸은 페이지와 함께 페이드 |
| 빈 칸 글자 안내(UI-ATTN-001) | 블록 변화 없이3초마다 빈 칸 중 무작위 한 칸의 글자만 DOPunchScale18%0.55초. 입력 잠금 없음 |
| 초과 블록 안내(UI-ATTN-001) | 그룹·제품2개 이상/색3개 이상이면 표시된 해당 블록이 즉시 DOPunchAnchorPos좌우10px0.45초, 유지되면3초마다 반복. 입력 잠금 없음 |
| 광고→영상 | 사용자 후속 지시로 암전0.5초→실제0번 프레임 준비/인계→암전 해제0.5초. 영상 표면은 불투명하게 유지하고 해제 중 연속 재생 |
| 우측 추천 이미지·광고 이미지 | 0.25초 InOutSine 페이드, 확대 없음 |
| 광고 물건 강조 | 물건 최전면. 큰 단발 별1.8초와 전체 화면 컨페티 약6초 자연 종료. 입력은 효과 시작 3초 뒤 허용하며 그때 버튼 안내가 0.25초 페이드로 표시된다(UI-ADHINT-001). 확대된 아우라는 초당10도로 화면을 떠날 때까지 반복하며 입력 잠금 대상에서 제외. [세부 설정·프리팹 검토](AD_PRODUCT_HIGHLIGHT.md) |
| 카드 숨김 | 현재 크기/투명도에서0으로,0.3초 InOutSine |
| 안내 이미지 표시/숨김·언어 페이드 | 투명도만0.25초 InOutSine |
| 기타 패널 | 이전 화면0.5초 퇴장 완료 후 다음 화면0.5초 등장, InOutSine |
| 씬 | 암전0.5초 → 다음 씬의 데이터/표시 준비 → 암전해제0.5초 |
| 기타 순차 항목 | 공통0.2초 간격 지원. 블록 네 칸에는 순차 지연을 적용하지 않음 |

상수는 `Assets/Scripts/UI/UIMotion.cs`에 모은다. DOTween은 `SetUpdate(true)`, 지연은 UnscaledDeltaTime, 언어 페이드는 실시간으로 진행하여 Time.timeScale=0에서도 동작한다. 카드의 최종 크기는 초기화 때 저장한 `transform.localScale`이다. `(1,1,1)`로 강제하지 않는다.

## 책임과 연결

- `UIPresentationTransitions`: GameManager가 소유하는 공통 전환/입력 잠금/암전 오버레이. GameManager에는 기존 씬 로드 전후의 연출 호출과 입력 잠금 확인만 추가했다. 씬 이동 목적지와 세션/미디어 정리 분기는 기존 코드가 결정한다.
- `UIScenePresentation`: 새 씬의 UI를 첫 렌더 전에 숨기고 언어/블록 설정이 준비되면 최종 레이아웃을 계산한다. 암전 해제 후 안내/네 블록 칸의 동시 페이드를 담당한다. 네 칸의 뾰잉은 신규 블록 ID가 인식될 때만 요청하며 해제·화면 진입·동일ID 반복 인식에서는 요청하지 않는다. 초기 설정이 실패해 준비되지 않을 때는16초 뒤 기존 표시 가능한 기본 UI를 복원하고 영문 진단을 남긴다. 별도 홈 이동이나 콘텐츠 재시도를 결정하지 않는다.
- `UIAnimatedElement`: 개별 패널/안내/카드의 표시 상태와 자신이 만든 Tween만 소유한다. 같은 표시 요청은 실행 중 작업을 공유하고, 반대 요청은 현재 투명도·크기에서 이어간다. 숨김이 완료된 뒤 비활성화하며 재진입 시 디자인 크기를 복원한다. Game의 생성 결과는 기존 활성화 시점에서 페이드하며 Result 광고 이미지도 페이드한다. 안내 팝업은 OutBack을 유지한다.
- `UIPopupPresentation`: 영상 종료/실패 안내에 공통 배경→팝업 순서를 적용한다. 영상 종료 텍스트와 테두리를 같은 PopupContent 안에 두어 함께 확대한다. 배경/카드가 숨은 상태로 준비된 뒤 활성화하며 취소 시 자기 배경과 잠금을 해제한다.
- `ResultVideoController`: 실제 첫 프레임 준비와 불투명한 영상 표면은 유지한다. 후속 요청으로 공통 암전/해제를 각0.5초 연결했으며 해제 중 영상은 연속 재생한다. 빈 영상 표면은 켜지 않고, 실패에는 광고 위에 기존 팝업을 표시한다. 홈 씬 전환이 암전을 소유하면 영상의 finally가 해당 암전을 지우지 않는다. 이 후속 후보의 실행 검증은 HANDOFF를 확인한다.
- `BlockExperienceView`: 그룹 인식 후 계속 입력으로 배치 화면에 들어간 상태를 유지한다. 이동 중/이동 후 그룹을 제거해도 되돌아가지 않고 선택 모델의 해당 슬롯을 비운다. 필수 블록이 부족하면 계속 안내/짧은 진행만 막고 재인식하면 기존 배치 화면에서 복구한다. 홈에서는 기존 세션 정리 후 새 그룹 화면으로 시작한다.
- `UIBlockSlotTransfer`: 그룹 프레임과 하위 BlockContent를 임시 이동 레이어에 옮겨 페이지 페이드의 영향을 받지 않게 한다. 목적지 그룹 칸은 이동 완료까지 비활성화한다. 프레임의 현재 렌더 모서리에서 목적지 모서리까지 위치와 크기를 함께 보간하고, 도착한 프레임과 동일한 모서리에서 목적지 칸을 활성화한다. 이동용 원본은 원래 부모/순서/앵커/피벗/위치/크기/회전/디자인 스케일로 복구하며, 홈/화면 종료에서 자기 Tween과 임시 레이어만 정리한다. 씬 암전 API는 호출하지 않는다.
- `UIMotionAuthoring.ConfigureScenes()`: 현재 UI를 재작성하지 않고 연출 컴포넌트만 연결한다. 카드의 확대 기준을 중앙으로 옮길 때 보정된 위치를 함께 적용해 최종 모서리 좌표는 유지한다. 기존 `ExhibitionUIBuilder`로 UI를 다시 만들 때도 같은 연결을 적용한다.

## 입력과 수명

공통 잠금은 마우스/터치를 투명 오버레이로 차단하고, 전시 버튼과 에디터의 블록 선택/제거 키에도 적용한다. 전환 중 버튼 입력은 저장하지 않는다. 잠금 시작/종료 때 제스처를 초기화하므로 눌린 채 넘어온 입력이 다음 화면의 짧은 입력으로 바뀌지 않는다. 선택 장비의 실제 블록 상태 데이터와 비동기 작업 결과는 기존 경로대로 처리하며 화면 상태 변경에 맞춰 연출만 갱신한다.

연령 단계는 연령 블록1개, 물품·색상 배치 단계는4개 모두 인식된 뒤 계속 안내를0.25초 페이드인하고 짧은 진행 입력을 허용한다. 필수 블록을 제거하면 안내를 페이드아웃하고 짧은 진행 입력을 즉시 차단한다. 인식 전 입력은 다음 단계에 쌓아두지 않는다. 기존5초 홈은 부족한 블록이 있어도 유지한다. 패널 퇴장·등장과 내부 연출까지 완료하면 다음 버튼 입력을 허용한다. 영상의 첫 표시 준비에도 같은 잠금을 사용하고, 재생 중 전체 시간을 잠그지는 않는다. 따라서 재생 중5초 홈은 기존대로 동작한다. 운영자용 D/I/M/F 단축키나 무입력 타이머 정책은 변경하지 않는다.

개별 Tween/CTS만 취소하며 전역 KillAll을 사용하지 않는다. 씬 로드는 기존 취소/세션 경로를 보존한다. 연출 실패/취소에는 공통 `finally`가 암전을 지우고 입력 잠금을 해제하며, 이미 로드한 씬의 표시 가능한 UI를 복원한다. 화면 재진입 시 이전의 반투명/중간 확대 상태를 재사용하지 않는다.

## 검증 증거

- `docs/validation/ui/motion.json`: 39항목 PASS. 비단위 디자인 크기·OutBack 초과/안착, 동일 요청 공유, 표시/숨김 역전, 취소/비활성화, 팝업 순서/시간, Time.timeScale=0, 입력 무시/해제, 실제 씬/패널 전환과 네 칸 동시 페이드·배치 시에만 뾰잉·추천/광고 이미지 페이드, 필수블록 부족/제거/재인식 시 안내·입력, 기존 색칠/Result/홈 연결.
- `motion_ui_regression.json`, `motion_color_regression.json`: 기존 UI/색칠 시나리오에 연출 완료 대기만 추가한 재실행 결과. 실제 통과 여부와 개수는 HANDOFF에 기록한다.
- `motion_preservation.json`: 작업 전후 원본 콘텐츠·설정·선택/색칠/입력 파일의 해시 비교.
- `slot_transfer_motion.json`: 그룹→배치의 암전 없는 동시 이동, 이동 중 목적지 비활성/원본 네 칸 불투명·하위요소 보존, 정확한 도착 모서리/원래 계층 복구, 이동 중/후 그룹 미인식 시 배치 유지·계속 차단, TH/EN 반복 진입·홈 중단 정리. 이 보고서가 이전 `motion.json`의 그룹 해제 시 이전 패널 복귀 검증을 대체한다.
- `video_first_frame.json`: 실제 네이티브 디코더의 frameReady0·첫 Canvas 표시0·첫 이미지의 색/알파·준비/인계 중 화면 덮임·즉시 프레임 진행·오디오 복원·실패 재시도/홈/종료 자원 정리. `video_first_*_screen.png`는 실제 첫 표시 화면 캡처다.

Windows Player/실물 버튼·RFID/최종 장비에서의 프레임 시간·GC/장시간 검증은 이 에디터 검증으로 대체하지 않는다.
